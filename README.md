# Rally-X Style Mobile Game

A web-based mobile game inspired by Rally-X, featuring a scrolling car game with special powers and collectible chests.

## Features

- **Scrolling Gameplay**: Player car stays centered while the world scrolls around
- **AI Opponents**: Enemy cars that chase the player
- **Rocket Power**: Throw rockets to destroy enemy cars
- **Collectible Chests**: Gather chests to gain superpowers:
  - **Invisibility**: Become temporarily invisible to enemies
  - **Speed Boost**: Move faster for a limited time
  - **Bomb**: Place a bomb that explodes after a delay
- **Mobile Optimized**: Touch controls and responsive design
- **Score System**: Earn points by destroying enemies and collecting chests

## Controls

### Desktop
- **WASD** or **Arrow Keys**: Move car
- **Space**: Shoot rocket

### Mobile
- **D-Pad**: Move car
- **🚀 Button**: Shoot rocket
- **💣 Button**: Place bomb (when power is active)

## Getting Started

1. Open `index.html` in a web browser
2. Click "Start Game"
3. Use controls to move and shoot
4. Collect chests for special powers
5. Avoid enemy cars!

## Deployment
